    使用帮助

    1 · 上传

    把 GPX / FIT / TCX / KML / CSV 文件拖进页面，或点「选择文件」。FIT 为 Garmin / COROS / 高驰等设备的二进制格式；CSV 需含 lat,lon（可选 time,ele,hr,cad,power）等常见列名。所有解析都在本地完成。

    2 · 裁剪头尾

    默认「裁剪头尾」模式：在剖面图上拖动选出要保留的范围，或直接拖动两端的「起 / 止」手柄；也可在下方输入精确的起点/终点（时间轴为 时:分:秒，距离轴为公里）。地图上的绿点为起点、红点为终点。

    3 · 删除中间片段

    切到「删除中间」模式，在曲线上拖出一段即可删除（如等红灯、GPS 漂移、中途搭车）。可删除多段，下方红色标签点 × 可撤销。删除后时间轴可选「保留空档」（平台识别为暂停）或「前移补齐」（轨迹连续、总时长变短）。

    4 · 缺失数据修复

    左侧「数据体检」会列出缺失项。常见处理：

    • 无时间戳：设置起始时间 + 采样间隔自动补全（FIT 必须有时间）。
    • 坐标无效 / 缺失：自动剔除 Null Island (0,0) 与越界点。
    • 无海拔：可不导出，或填固定值。
    • 无距离 / 速度：按坐标与时间自动推算。
    • 完全无坐标（室内活动）：只能导出 FIT，GPX 按钮会禁用。

    5 · 导出

    设置活动名称与运动类型后，点「导出 GPX」或「导出 FIT」。GPX 含心率/步频/功率扩展；FIT 为标准活动文件（file_id + record + lap + session + activity，带 CRC 校验），可直接导入 Garmin Connect / COROS / Strava。
