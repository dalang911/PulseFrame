# Documentation

English is the primary language of this documentation set. The original Chinese
notes are archived under [`zh/`](zh/) — useful for reading the existing comments
in the code, but the files here are the reference.

| Read this | When |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | You want the module map, the event contract, and where state lives |
| [DATA_SCHEMA.md](DATA_SCHEMA.md) | You are touching parsers or the pipeline and need the exact field names |
| [COMPONENT_GUIDE.md](COMPONENT_GUIDE.md) | You are writing your first dashboard component |
| [COMPONENT_JSON_SPEC.md](COMPONENT_JSON_SPEC.md) | You need the template/layout JSON format |
| [DEPLOYMENT.md](DEPLOYMENT.md) | You are hosting the frontend and need the API-address rules |
| [../SECURITY.md](../SECURITY.md) | You found or want to verify a frontend protection |
| [../THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) | You are redistributing this code |
| [../CONTRIBUTING.md](../CONTRIBUTING.md) | You are opening a pull request |

Documentation policy: a document states the constraint that shaped the code, not
a restatement of the code. If a doc and the code disagree, the code is right and
the doc is a bug — please fix it in a PR.
